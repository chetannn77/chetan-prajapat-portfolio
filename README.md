# Chetan Prajapat — Personal Portfolio Website

**"Building My Future, One Skill at a Time."**  
*Practical Thinker. Self-Taught Learner. Business Builder. Future-Focused Creator.*

This repository contains the complete source code for the personal portfolio website of **Chetan Prajapat**—a stainless steel fabrication contractor, practical project coordinator, and self-taught digital learner from Bichhawadi, Rajasthan, India.

The website is built with pure **HTML5**, **CSS3**, and **Vanilla JavaScript** with zero external frameworks or build tools required.
